# Onboarding new engineers

## First day

New engineers receive a laptop with disk encryption enabled and a temporary password that must be
changed at first sign-in. Their manager assigns an onboarding buddy.

## First week

By the end of the first week, engineers get read access to the main repositories, join the on-call
shadow rotation and complete the security awareness training.

## Tools

The team uses the internal chat for daily communication and the ticketing system for all work
requests.
